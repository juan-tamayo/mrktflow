# ADR-005: Independent runtime with optional services

Status: Proposed · Date: 2026-10-05.

## Context

The user confirmed free/open-source distribution and installation under store-owner control.

## Decision

No platform subscription, required license activation, mandatory vendor analytics or hosted control plane. Core catalog, content and order history work locally. Merchants supply payment/email/AI credentials; AI is optional. Distribute versioned packages, compiled assets and maintenance documentation.

## Alternatives

A required hosted authoring/billing service simplifies centralized management but undermines independent operation. Bundled platform-funded AI would need a funding/abuse model not requested here.

## Consequences

Maintainers must document installation and supported updates. External provider fees and hosting remain merchant concerns. Final open-source license and governance are unresolved release decisions; no license file has been asserted yet.
